## KrameWork - PHP Web Framework

### What is this?
For a long time, sites I developed would be based on [KrameWork5](https://github.com/Kruithne/KrameWork5), however as time has gone on, this has become more and more out-of-date. With the release of PHP 7, rather than combing through the code-base and updating things, I redesigned the framework from the ground-up using newer features and tech.

### What version of PHP does it support?
KrameWork requires PHP 8.0 or later. It is kept up-to-date with the latest release of PHP, including removal of deprecated functions and support for new shiny language features.

### It's not very frameworky..
Rather than following [KrameWork5](https://github.com/Kruithne/KrameWork5) in trying to be a framework, KrameWork acts more like a toolkit. If you're quickly trying to spin up a script or mini-site, and you want the functionality of auto-loading provided by KrameWork, you can simply create a new `AutoLoader` instance and you're good to go, no need to fiddle about with framework configurations, dependencies or bootstraps. 

### Disclaimer
This is a personal project, intended for use on other personal projects. I make no promises about the performance or reliability of the framework, however it is in my best interest to make it as solid as possible. If you find any issues or room for improvement, feel free to contribute.
